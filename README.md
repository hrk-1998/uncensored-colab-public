[باز کردن در Google Colab](https://colab.research.google.com/github/hrk-1998/uncensored-colab-public/blob/main/Uncensored.ipynb)

## کار شما

1. Runtime را روی **GPU** بگذارید (T4 یا بهتر).
2. **Run all** را بزنید.
3. صبر کنید تا نصب، دانلود مدل و بالا آمدن صفحه تمام شود.
4. لینک `gradio.live` که آخر نوت‌بوک چاپ می‌شود را باز کنید.
